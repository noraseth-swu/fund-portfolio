# Anti-Slop Audit Report #001

- **Date:** 2026-11-14
- **Project:** Thai Mutual Fund Portfolio Manager (`fund-portfolio`)
- **Scope:** Complete project audit (Frontend UI/UX, Typography, Code Hygiene, Accessibility)
- **Status:** Review Only (No modifications applied yet)

---

## Summary of Findings

| # | Priority | Rule / Principle | Category | Finding & Recommendation |
|---|:---:|:---:|:---:|---|
| **1** | **HIGH** | **R-03** | Accessibility / Mobile | **Tap Targets Below Minimum (44px):** ปุ่มไอคอนขนาดเล็ก เช่น Theme Switcher (`p-1.5` ~28px), ปุ่มถังขยะลบรายการ (`p-1.5`), และปุ่มปิดกากบาท (`p-1`) มีขนาดเล็กกว่า 44px ซึ่งกดบนมือถือยาก แนะนำเพิ่ม padding หรือ minimum touch container 44x44px |
| **2** | **HIGH** | **R-23** | Visual Identity | **Assumed App Logo / Icon:** การใช้ไอคอนรูปกระเป๋าเงิน `<Wallet>` บนพื้นหลังสีม่วง Gradient เป็นโลโก้สำเร็จรูปที่ AI มักเลือกใส่เองตามสัญชาตญาณ แนะนำเปลี่ยนเป็นตัวอักษรย่อแบรนด์เฉพาะตัว หรือสัญลักษณ์ที่เรียบง่ายและเป็นเอกลักษณ์ของกองทุนรวมไทย |
| **3** | **MEDIUM** | **R-01** | Visual Design | **Ambient Radial Glow (ลูกบอลเรืองแสงเบลอ):** ในหน้า Signed Out View มีการใช้ `blur-3xl bg-gradient-to-tr ...` ขนาด 600x350px ฟุ้งอยู่ด้านหลัง ซึ่งเป็นสไตล์ตกแต่งยอดฮิตของ AI Landing Page โดยไม่ได้มีประโยชน์เชิงการใช้งานจริง แนะนำนำออกแล้วใช้พื้นหลังเรียบสะอาดหรือโครงสร้างมิติแสงที่ดูเป็นมืออาชีพ |
| **4** | **MEDIUM** | **R-22** | Iconography | **Excessive Sparkle Cliché (ใช้ประกายดาวมากเกินไป):** มีการใช้ไอคอน `<Sparkles>` พร้อมคลาส `animate-pulse` ซ้ำซ้อนถึง 7 จุดในแอป เพื่อสื่อถึงฟีเจอร์ AI (เช่น หัวข้อ Modal, ปุ่มนำเข้า, ปุ่มวิเคราะห์, แถบ Token) ซึ่งดูเป็นสูตรสำเร็จของ AI UI แนะนำลดเหลือเฉพาะจุดสำคัญ และใช้ไอคอนที่สื่อความหมายจริง (เช่น สัญลักษณ์เอกสาร, การสแกน หรือไอคอนโมเดล) |
| **5** | **MEDIUM** | **R-07** | Component Shape | **Excessive Border Radius (มนเกินไปทุกองค์ประกอบ):** ทุกการ์ดใช้ `rounded-2xl`, ทุกปุ่มใช้ `rounded-xl`, แท็บใช้ `rounded-full` ทั้งหมด ทำให้ไม่มีคอนทราสต์ทางรูปทรง (Shape Hierarchy) แนะนำปรับการ์ดหลักและการ์ดตารางให้เป็น `rounded-xl` หรือ `rounded-lg` เพื่อให้ UI ดูมีความเฉียบคมและน่าเชื่อถือแบบ Financial Dashboard |
| **6** | **MEDIUM** | **R-08** | Trend-Stacking | **Colored Shadows & Glassmorphism ซ้อนทับกันมากไป:** การใช้เงาสีม่วง/เขียว (`shadow-indigo-600/30`, `shadow-emerald-900/30`) คู่กับ `backdrop-blur` บนหัวตาราง การ์ด และ Modal พร้อมกัน ทำให้หน้าจอรู้สึกลอยฟุ้ง แนะนำใช้เงาธรรมชาติ (Neutral subtle shadow) ที่เน้นบอกระดับความลึก (Z-index elevation) |
| **7** | **MEDIUM** | **R-16** | Copywriting | **AI Marketing Buzzwords & Decorative Arrows:** คำบรรยายภาษาอังกฤษและไทยบางส่วนดูเป็นข้อความ AI เกินจริง เช่น *"AI Intelligent Processing"* (ประมวลผลข้อมูลอัจฉริยะ), *"Universal ... Aggregator"* และลูกศรลอยหลังปุ่ม `ปลดล็อก & วิเคราะห์ด้วย AI →` แนะนำปรับเป็นภาษาที่กระชับ ตรงไปตรงมา เช่น *"กำลังอ่านและสกัดข้อมูลด้วย Gemini"*, *"ระบบจัดการพอร์ตลงทุนกองทุนรวม"* |
| **8** | **LOW** | **Antislop-Code** | Code Hygiene | **Redundant AI Commenting (คอมเมนต์อธิบายสิ่งที่โค้ดบอกอยู่แล้ว):** ในโค้ด JSX มีคอมเมนต์บรรยายทุกบล็อก เช่น `// Header Navigation`, `// Greeting banner`, `// Top 4 Summary Cards`, `// Filter Tabs`, `// Table` ซึ่งเป็นลายเซ็นต์ของ AI Slop โค้ดควรชัดเจนในตัวเองและลบคอมเมนต์ที่บรรยายซ้ำซ้อนออก |
| **9** | **LOW** | **Antislop-Human** | Accessibility | **Missing Keyboard Focus Affordance & ARIA Labels:** ปุ่มที่เป็นไอคอนล้วน (เช่น ปุ่มสลับธีม 3 ปุ่ม, ปุ่มประวัติ, ปุ่มลบธุรกรรม) ยังขาด `aria-label` สำหรับ Screen Reader และขาด `focus-visible:ring-2 focus-visible:ring-offset-2` สำหรับผู้ที่ใช้งานผ่านแป้นพิมพ์ (Tab navigation) |
| **10** | **LOW** | **Antislop-Layoutmobile** | Layout & Table | **Desktop-Heavy Table on Mobile Statement Importer:** หน้าต่างตรวจสอบรายการที่สกัดจาก Statement เมื่อเปิดบนจอมือถือ ตารางมีความกว้างมากกว่าหน้าจอจนต้องเลื่อนแนวนอนหลายทอด แนะนำเพิ่ม Responsive Card View สลับแสดงผลเป็นการ์ดสรุปรายการย่อยเมื่อหน้าจอแคบกว่า 640px |
